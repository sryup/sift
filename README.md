# Sift

A lightweight, portable Linux system information tool written in POSIX-compatible shell (`sh`).

Sift collects and presents a concise snapshot of essential system information with minimal external dependencies, without requiring heavy runtimes or background daemons.

## Philosophy

- **Minimalism:** Essential system details over cluttered feature sets.
- **Portability:** Strict POSIX `sh` compatibility to run across diverse Linux distributions.
- **Readability:** Clean, understandable code that is easy to audit and maintain.
- **Reliability:** Graceful handling when system data or hardware sensors are unavailable.

## Status

Sift is currently in early development.
